# A-90 Doors

## English
Hi! This is the **A-90 Doors** project. 

**Disclaimer:** This is **NOT a real virus**. It is a harmless "prank virus" application / interactive digital quest built purely for educational purposes. It does NOT steal, destroy, or delete any user data or system files. I am strictly against real malware!

### How it works:
* **The Gameplay:** When launched, a window featuring a monster from the popular game *Doors* appears on top of other windows, along with a countdown timer. 
* **The Goal:** The user has to find a secret password to unlock the application. 
* **The Hint:** The password is safely hidden inside a file within a well-known system directory (`AppData`). 
* **The Finale:** Once the correct password is typed into the text box, the application safely closes itself. Nothing bad happens whether you win or lose — it is just a safe, fun joke game for friends.

Программа НЕ ворует, НЕ уничтожает и НЕ удаляет данные пользователя или системные файлы. Я категорически против вредоносного ПО!

### Как это работает:
* **Игровой процесс:** При запуске открывается окно с монстром из игры *Doors*, которое висит поверх других окон, и включается таймер обратного отсчета.
* **Цель:** Пользователю нужно найти секретный пароль, чтобы разблокировать приложение.
* **Подсказка:** Пароль надежно и безопасно спрятан в файле внутри всем известной системной папки (`AppData`).
* **Финал:** Как только правильный пароль введен в текстовое поле, программа полностью закрывается. Ничего плохого не произойдет ни при выигрыше, ни при проигрыше — это просто безопасный розыгрыш для друзей.
